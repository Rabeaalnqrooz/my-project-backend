# 🛒 E-Commerce API (Backend)

الخلفية البرمجية (RESTful API) لطلب منصة التجارة الإلكترونية. توفر المنصة خدمات المصادقة، إدارة المنتجات، إدارة السلة والطلبات، والتعامل مع الصور.

## 🔗 Related Repositories

- **Frontend App:** [my-project-frontend](https://github.com/Rabeaalnqrooz/my-project-frontend)
- **Live Demo:** [Julia Store](https://julia4-store.vercel.app)

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **ORM/ODM:** Mongoose
- **Authentication:** JWT (JSON Web Tokens) & Email Verification
- **File Storage:** Cloudinary

## ✨ Key API Features

- 🔐 **Auth System:** تسجيل حساب جديد، تأكيد البريد، وتسجيل الدخول.
- 📦 **Products Management:** عمليات CRUD للمنتجات والتصنيفات.
- 🛒 **Cart & Orders:** معالجة السلة وتخزين الطلبات.
- 🛡️ **Security:** تشفير Passwords باستخدام Bcrypt وحماية من الـ Spam عبر Rate Limiting.
